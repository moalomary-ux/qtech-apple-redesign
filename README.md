# QTECH Apple Redesign

Apple-inspired redesign for QTECH design system.

- **Home** — Dashboard with KPIs, quick links, and attention items
- **Login** — Secure login with OTP, theme-aware design
- **Gov360 ID** — Government entity profile with charts and decisions

- Dark / Light theme toggle
- Page transition animations
- Mobile-responsive sidebar with overlay
- Glass-morphism app bar
- Apple-inspired design system
